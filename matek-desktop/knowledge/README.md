# Local reference notes

Add your own small `.md` or `.txt` notes here, preferably with a source and version/date. The companion reads relevant notes only when a question is asked. It does not upload them, fetch updates, execute their contents or train a model on them.

Examples: recipes, your game's version-specific instructions, verified troubleshooting steps, or notes about a topic you study. Existing source URLs are provenance, not automatic web access. Update notes yourself when their facts change.

Lookup scans at most 100 top-level files of up to 32 KB, and selects at most two 2,500-character excerpts using local word matching. This is small local reference retrieval, not a comprehensive search engine. Avoid putting sensitive documents here unless you deliberately want to use them as context. If cloud is enabled in future, selected excerpts become part of the authorized request preview.
